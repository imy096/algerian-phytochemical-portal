Stage 1: Elicit Plant Data Processing

This folder contains all the scripts needed for the first stage of the project. In this stage, we process raw Excel files extracted from Elicit, each representing literature on a specific Algerian medicinal plant.

What These Scripts Do
Prepare Inputs: Organizes raw Excel files into the appropriate directory structure.
Filter Rows: Keeps only rows that actually mention the target plant in relevant fields.
Consolidate Evidence: Combines multiple article rows into a single, structured evidence record per plant.
Refine Data: Removes redundant or irrelevant text, making the data cleaner.
Extract Compounds: Pulls out chemical compounds, linking them to reference indices and DOIs.
Audit Quality: Checks the accuracy and completeness of the extraction.
Output of This Stage
Cleaned, consolidated plant data files.
A structured compound list with references.
Audit reports to ensure quality.

These outputs will be used in the next steps of the project, such as database building and further analysis.
