# Project Overview

## Title
Algerian Phytochemical Chemogenomic Database and Research Portal

## Description
This project aims to build an integrated chemogenomic database for Algerian medicinal plants by linking phytochemical compounds, plant taxonomy, molecular targets, transcriptomic signatures, and biological evidence.

## Objectives
- Extract phytochemical data from literature and PDFs
- Normalize and clean plant and compound data
- Enrich compounds using external databases (PubChem, KEGG, STITCH, LINCS, GEO, CompTox)
- Prepare structured datasets for database integration
- Build a web-based database portal for exploration and analysis

## Scientific Contribution
This platform enables:
- cross-database integration
- hypothesis generation
- chemogenomic exploration of medicinal plants

## Pipeline Summary
The project is structured into multiple stages:
- Stage 1: Data extraction and cleaning
- Stage 2: Compound enrichment
- Stage 3: Database preparation
- Stage 4: Database application construction
